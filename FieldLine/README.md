# FieldLine iPhone 原型

根据 `FieldLine_MVP_需求与开发文档_v1.0.docx` 创建的独立 SwiftUI 工程。iOS 17+，Xcode 16+ 工程格式，已在 Xcode 26.4 编译。无第三方依赖、无服务器，所有场地和划线记录保存到 App Documents 的 `fieldline-fields.json`。现有 AAYSA Sports 工程未修改。

## 打开运行

1. 打开 `FieldLine.xcodeproj`，选择 `FieldLine` scheme。
2. 选择 iPhone 模拟器，点击 Run。
3. 真机运行时，在 Signing & Capabilities 中选择自己的 Development Team；如有需要修改 Bundle Identifier（当前为 `com.globjoy.fieldline`）。
4. 新建场地并保存，打开场地详情，选择现场校准。
5. 真机允许“使用 App 期间”定位和精确位置。保持 App 在前台使用。

现场校准时，在任意外角选择 A/B/C/D，点按“Set Point”。App 至少采样 3 秒，优先等待 GPS 水平精度达到 ±5 m；若未达到，会继续等待，最多 20 秒。青少年比赛的粗校准可接受 ±12 m 内的采样。成功后第一个角在图上显示 ✓。第二次选择目标标准角（例如从 D 指向 C），可以走到该角，也可以只沿该方向走一段。若明确未到目标角，打开“此点仅指定方向”；即使定位误差使点位接近目标角，也会按方向点处理。若未打开但第二次实测距离比模板角距短超过 15%，App 同样会询问是否沿该方向自动延伸到模板角。方向段至少要达到 15 m 或模板角距的 35%（两者取较大值）。确认后，实测方向点显示橙点，推算目标角显示橙圈“推”；只有真正实测的角显示 ✓。过短的方向段会提示走远后重采；超过模板角距 15% 以上则提示核对字母或场地尺寸。返回场地详情后，蓝色“你”会随定位移动，定位较弱时显示橙色；定位暂未更新时保留橙色“上次位置”并请求新定位。页面显示 GPS 水平精度、实测方向段与模板角间距。按方向延伸的校准默认使用比赛级人工对准。若采样只取得一个符合门槛的定位，仍会提示未平均，建议重新采样。

在“开始划线”页，粗校准默认进入“比赛级人工对准”：现场确认起点、方向和终点后手动开始与结束，地图中的 GPS 点只作大致位置提示，不显示米级纠偏或终点提醒。也可从 GPS 导航页主动切换到人工模式。人工记录单独标注，不把 GPS 偏差统计当作实际划线精度。

模拟器可浏览模板、创建和保存场地；现场校准和导航依赖位置输入，不会默认注入虚假 GPS。核心算法测试使用独立的合成轨迹。

## 已实现

- 7v7 / 9v9 / 11v11 JSON 参数模板和 Custom 比例策略。
- 7v7 依实际场地移除小禁区，加入两条球门球回撤线（build-out line）；回撤线位于各端禁区前沿与中线的中间。已有 7v7 场地在重新打开时保留校准位置并更新线条。
- Canvas 场地图，四角、主要内部节点、直线、中圈及禁区弧。
- 任意两个不同外角（含对角）校准；第二点可只指定方向，确认后按模板距离投影，并将实测方向点与推算角分开显示。校准后在场地详情实时显示手机的估算位置和 GPS 精度。
- 3 秒定位采样、精度和时效过滤、异常点过滤。
- 仅显示当前节点直接相连的线段，可双向行走。
- 方向校准、对准、倒回起点、准备划线、划线、完成状态。
- 由连续 GPS 位移估算行进方向；横向偏差、沿线进度、终点距离与弱信号提示。
- 5 m / 2 m / 到达及越过终点提示，震动提醒，划线页防息屏。
- 本地原子保存场地、校准及完成后的轨迹和误差统计。
- 首页“辅助工具 → 球门放置”：直接采集同一底线上、同类且左右对称的两个基准点定位球门中心，无须选择角点或禁区点类型；球门宽度默认 5 m，可直接修改，也可采集球门两个端点，将 GPS 算出的宽度自动填回同一输入框。短距离 GPS 结果需用卷尺复核。
- 首页“辅助工具 → GPS 采点与距离分析”：按任意顺序记录 GPS 点。采点形成可识别的外框及同端禁区前角后，自动拟合场地，不按记录顺序连线；可进一步识别球门区前角、点球点，让同端标记按拟合中轴居中，并向另一端镜像补线。每条线直接标米数。原始 GPS 点单独保留，任意两点也可测距或手动补画线。退出后可重新打开，并可分别分享原始采点、显式连线和复原几何 CSV。
- 采点记录列表支持左滑删除、右滑编辑名称；删除前需要确认。

## 文件结构

- `FieldLine/Core/Geometry.swift`：几何模型、模板策略、球面距离/方位/投影、局部米制运算、统一阈值。
- `FieldLine/Core/Navigation.swift`：导航状态机、轨迹和持久化数据模型。
- `FieldLine/Resources/Templates.json`：原型尺寸参数，正式采用前需按当地规则确认。
- `FieldLine/FieldStore.swift`：本地保存和 Core Location 采样。
- `FieldLine/FieldCanvas.swift`：场地图。
- `FieldLine/Assets.xcassets/AppIcon.appiconset`：1024 px iOS App 图标；`design/足球场划线机与球门-原图.png` 保存用户提供的图片，`design/FieldLine-AppIcon-master.png` 是去白边后的母版，`design/generate_app_icon.py` 可从母版重新生成图标资源。
- `FieldLine/Core/GPSSurvey.swift`：带场地位置的采点、按模板拓扑自动连线、显式补画线段、地表测距和 CSV 数据。
- `FieldLine/Core/SurveyInference.swift`、`SurveyReconstruction.swift`：无序采点的四角与内部标记识别，以及居中、镜像补线和复原几何导出。
- `FieldLine/GPSLogsView.swift`：GPS 采点画布、列表及导出。
- `FieldLine/FieldLineApp.swift`：主页、新建、详情、角点校准和线段选择。
- `FieldLine/MarkingView.swift`：现场 HUD 和划线记录。
- `Tests/FieldLineCoreTests`：纯逻辑单元测试，通过 Swift Package 运行。

A=(0,0)，B=(宽,0)，C=(宽,长)，D=(0,长)。本地 x 向右，y 向下；使用旋转映射到地理坐标。`fieldBearing` 表示本地 +x 的地理方位角。横向偏差为正表示行进方向右侧，提示向左修正。点位使用米制坐标并保存生成策略版本，避免重新打开时重新生成几何。

## 验证命令

在本目录运行：

```sh
swift test
xcodebuild -project FieldLine.xcodeproj -scheme FieldLine \
  -sdk iphonesimulator -destination 'generic/platform=iOS Simulator' \
  -derivedDataPath DerivedData CODE_SIGNING_ALLOWED=NO build
```

28 个 XCTest 用例覆盖：十二种不同角点组合（含对角）× 六种旋转；非法角点/过近角点；比赛级粗校准的 GPS 和角间距离门槛；人工划线记录和旧版记录兼容；双向横偏符号与沿线进度；Custom 缩放与相连线段；保存编码往返；合成轨迹完整状态流程和弱信号；反向行走和过期位置；无序采点、场地节点自动连线、显式线段与 CSV；23 点样本的四角/禁区/球门区/点球点识别、居中与镜像、逆序采点及逐步采集的四个阶段；3 秒静止采样的异常点过滤与采样明细保存；旧采点记录兼容；7v7 复原不含小禁区、自动补回撤线，以及旧场地升级。

## GPS 采点记录

首页进入“辅助工具 → GPS 采点与距离分析”，创建一份记录，默认选 9v9 场地结构，可改为 7v7、11v11 或自由采点。采点顺序只用于编号和保存，不表示行走路径。每记录一个点立即重新计算并更新一览：识别出外框四角后先补全外框和中线；随后采到同端禁区前沿两个角，就补两端禁区；球门区前沿两个角到齐后补两端球门区；点球点出现后补两个居中点。程序从凸包拟合四角，找同端禁区前角，再找球门区前角和点球点；禁区与球门区的宽度和深度取实测值，但以外框中轴居中；另一端按镜像补齐。选择 7v7 时不生成小禁区，并在禁区与中线之间补球门球回撤线。原始点为橙色，拟合线为实线，镜像补线为虚线。点球点同样显示居中后的推算标记；原始点 23 等仍可独立查看。复原线的米数直接在线上。当前复原基于点位几何识别，对不规则或采样不足的场地可能无法识别；这时仍可标注 A/B/C/D 和其他场地节点，让模板按拓扑画线，或手动补画。复原画布按场地长边对正，便于容纳线段米数；尚未识别场地时为北在上、东在右。任意两点可测距。

在记录列表左滑可删除整份记录及其中全部采点，右滑可编辑记录名称；编辑名称不会修改采点数据。

站稳后点按采样按钮，画面倒计时 3、2、1；这 3 秒内若取得多个有效定位，会剔除明显跳动后加权平均；若只取得一个有效定位，仍会保存该点，但明确提示未平均并建议重测。合成点和全部原始定位明细均保存在 App Documents 的 `fieldline-gps-surveys.json`，包括 WGS84 经纬度、时间、设备报告的水平精度及是否参与平均。旧版单次采点仍可读取；新采样不凭多次平均人为缩小设备报告的水平精度。模板类型和显式补画线段也保存在同一份记录中；旧版记录可直接读取，原有采点不会被修改。过期定位不会参与采样；3 秒窗口内水平精度超过 15 m 的定位不会参与平均。没有有效定位时不写入点位，会显示失败原因；可在开阔处站稳重试。点击“导出采点 CSV”“导出 3 秒采样明细 CSV”“导出线段 CSV”或“导出复原标线 CSV”，可分别取回合成点、原始定位、显式连接和带 `source` 类型的推算线/点。复原图形是场地模型而非逐线实测；原始 GPS 坐标和水平精度是分析现场偏差的依据。3 秒采样可减少偶发跳动，但树木、建筑遮挡等共同偏差不会因短时平均消失；它也不能单独证明实际场地本身是否不对称。

## 当前边界

这是可编译运行的 MVP 原型，尚未验证草坪划线精度。阈值集中在 `NavigationThresholds`，包括优先 GPS ±5 m、比赛级粗校准最大 ±12 m、第二点距模板角距 15% 内视为实测角、方向段至少 15 m 或模板角距 35%、方向最小移动 4 m、对准 ±5° 持续 2 秒、起点/终点容差 1.5 m、轻微横偏 0.25 m。粗校准仅供俱乐部比赛场地布局参考，阈值不代表手机的真实测量能力，必须通过草坪实测后调整。

圆和弧已建模并渲染，目前没有曲线实时导航，需人工完成。未实现 Core Motion 融合、后台定位、云同步或自动控制喷漆。App Store 截图位于 `AppStoreAssets/screenshots`，公开的支持和隐私页面源码位于 `AppStoreAssets/site`。真实设备签名与草坪测试需使用你的开发团队及 iPhone。

只有手动结束线段后才保存轨迹记录；划线中强制退出不会保存未结束会话。App 不自动判定施工完成，操作者需关闭喷漆并确认结束。
